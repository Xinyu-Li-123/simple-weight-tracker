# i18n

## Usage in components

```tsx
import { useTranslation } from "@/i18n";
const { t } = useTranslation();
t("common.save"); // literal key — autocompleted
t("confirm.deleteRecordDesc", { date, weight }); // with interpolation
```

For **computed/dynamic keys** (e.g. `t(\`nav.${id}\`)`) use`tUnsafe("nav." + id)` — bypasses strict types.

## Usage in .ts files

```ts
import { i18n } from "@/i18n";
i18n.t("trend.continue");
```

## Adding a language

1. Create `src/i18n/locales/<code>.json` with all keys matching `en.json`.
2. Import it in `src/i18n/index.ts` and add to the `resources` map.
3. Add entry to `SUPPORTED_LANGUAGES` in `src/i18n/languages.ts`.

No TypeScript type changes needed — types derive from `en.json`.
