# Simple Weight Tracker

> [!WARNING]
> This codebase is fully generated by ChatGPT and codex I have not reviewed it.

An offline-first iOS-installable PWA for private local weight tracking.

## Start from scratch

```bash
pnpm install
pnpm dev
```

## LAN preview on iPhone

```bash
pnpm dev:host
```

Open `http://YOUR_LAN_IP:5173` on iPhone Safari. This is only for UI testing, not full PWA testing.

## Production preview

```bash
pnpm build
pnpm preview
```

## GitHub Pages deployment

This project assumes the repository is named `simple-weight-tracker` and deploys to:

```text
https://YOUR_USERNAME.github.io/simple-weight-tracker/
```

Before deploying, check `vite.config.ts`:

```ts
base: "/simple-weight-tracker/";
start_url: "/simple-weight-tracker/";
scope: "/simple-weight-tracker/";
```

Deploy:

```bash
pnpm deploy
```

Then configure GitHub Pages to publish from the `gh-pages` branch.

## Important data boundary

The app code is hosted by GitHub Pages. Weight data stays in the user's local IndexedDB. Export JSON backups before changing device, deleting the app, clearing website data, or changing the deployment URL.
